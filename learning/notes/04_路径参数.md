# FastAPI 路径参数

## 什么是路径参数？

路径参数是URL路径中的变量部分，在FastAPI中使用花括号`{}`声明。例如，在路径`/items/{item_id}`中，`item_id`就是一个路径参数。

## 基本用法

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
def read_item(item_id: int):
    return {"item_id": item_id}
```

在这个例子中：
- `/items/{item_id}` 定义了一个包含路径参数的路径
- `item_id: int` 表示这个参数应该被转换为整数类型

## 类型转换和验证

FastAPI会自动执行以下操作：
1. 从URL路径读取`item_id`的值
2. 将字符串值转换为声明的类型（如`int`）
3. 如果转换失败（例如，传入"abc"而不是数字），返回适当的HTTP错误

支持的类型包括：
- `int`：整数
- `float`：浮点数
- `str`：字符串
- `bool`：布尔值
- 以及其他更复杂的类型

## 路径操作顺序

路径操作的注册顺序很重要。例如：

```python
@app.get("/users/me")
def read_current_user():
    return {"user_id": "the current user"}

@app.get("/users/{user_id}")
def read_user(user_id: str):
    return {"user_id": user_id}
```

在这个例子中，`/users/me`必须在`/users/{user_id}`之前声明，否则`/users/me`会被解释为`user_id`为"me"的路由。

## 预定义值

使用Enum可以限制路径参数的可选值：

```python
from enum import Enum
from fastapi import FastAPI

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"

app = FastAPI()

@app.get("/models/{model_name}")
def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}
    
    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}
        
    return {"model_name": model_name, "message": "Have some residuals"}
```

这样做的好处：
- 参数验证：只有枚举中的值才有效
- 代码补全和类型检查
- 文档中显示可选值

## 包含路径的参数

如果需要接收包含路径的参数（如`/files/images/logo.png`），可以使用：

```python
@app.get("/files/{file_path:path}")
def read_file(file_path: str):
    return {"file_path": file_path}
```

`:path`告诉FastAPI这个参数应该匹配任何路径。

## 使用Path增强参数

可以使用`Path`函数添加更多验证和元数据：

```python
from fastapi import FastAPI, Path

app = FastAPI()

@app.get("/items/{item_id}")
def read_item(
    item_id: int = Path(..., title="商品ID", ge=1, description="商品的唯一标识符")
):
    return {"item_id": item_id}
```

`Path`函数的参数：
- `...`：表示这是一个必需参数
- `title`：参数的标题（在文档中显示）
- `description`：参数的描述
- `ge`：大于等于（greater than or equal）
- `gt`：大于（greater than）
- `le`：小于等于（less than or equal）
- `lt`：小于（less than）

## 参数命名冲突处理

如果路径参数名称与函数参数名冲突，可以使用别名：

```python
@app.get("/items/{item_id}")
def read_item(item_id: int, q: str = None, item: dict = None):
    results = {"item_id": item_id}
    if q:
        results.update({"q": q})
    if item:
        results.update({"item": item})
    return results
```

这里，路径参数`item_id`与函数参数名不冲突。

## 源码剖析

在FastAPI源码中，路径参数由以下部分处理：

1. **路径解析**：在`APIRoute`实例化时，调用`compile_path`方法解析路径，提取路径参数名称和转换器。
2. **参数模型**：`Dependant`类的`path_params`字段存储路径参数信息。
3. **参数提取**：请求处理时，`request_params_to_args`函数从请求中提取路径参数。
4. **类型转换**：通过Pydantic模型进行验证和转换。

这种设计使路径参数处理既灵活又可靠。
