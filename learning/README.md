# FastAPI 学习项目

这个项目旨在帮助您系统地学习 FastAPI 框架，通过与 AI 编程助手的交互式学习与实践。

## 项目结构

- `example/`：用于运行文档中提供的示例代码
- `notes/`：学习 FastAPI 过程中的笔记，以 Notion 友好的格式记录
- `prompts/`：存放与 AI 助手交流的常用提示词

## 使用方式

1. **学习路径**：按照 `catalogue.md` 中的学习大纲逐步学习
2. **实践示例**：在 `example/` 目录中编写并运行示例代码
3. **记录笔记**：与 AI 助手交互，在 `notes/` 目录中记录学习笔记
4. **提问交流**：随时向 AI 助手提问，探索 FastAPI 的各个方面

## 学习建议

- 每次专注于一个概念
- 先理解概念，然后尝试编写并运行示例代码
- 将学到的知识记录在笔记中，方便日后复习
- 尝试修改示例代码，理解不同参数和配置的效果
- 定期回顾已学内容，巩固知识点

## 开始学习

请从 `catalogue.md` 文件开始，选择您想学习的内容，与 AI 助手进行交互式学习。
